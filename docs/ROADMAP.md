# Roadmap

## Foundation selesai

- Next.js App Router, TypeScript, Tailwind, route publik, dan dashboard placeholder.
- Supabase browser/server utilities serta konfigurasi environment.
- Schema multi-tenant awal, enum role/status, seed sekolah, dan RLS awal.
- Dokumentasi arsitektur, keamanan, deployment, dan backup.

## Tahap berikutnya

- Implementasi Auth end-to-end: register, verifikasi email, login, logout, forgot/reset password.
- Profile dan membership approval server-side.
- PWA manifest, service worker, dan offline strategy.
- Modul siswa, guru, orang tua, presensi, agenda, dan dokumen.
- Storage metadata, private bucket policies, signed URL, audit log, dan observability.
